# Changelog

All notable changes to the Sensemaking Protocol are recorded here.

## Sensemaking Skill v0.2.0 — 2026-08-22

- Separated the internal reasoning protocol from the user-facing interaction model.
- Replaced the mandatory visible framing gate with transparent inference and selective clarification.
- Added next-best-reasoning-move behavior for clarification, inference, challenge, generation, connection, discrimination, contradiction, zoom-out, convergence, action, and summary.
- Required active agent contribution rather than protocol-field interrogation.
- Added nonlinear case-state updates and natural evidence handling.
- Added three levels of progressive disclosure: conversation, checkpoint, and full artifact.
- Added behavioral cases for conversational quality, reframing, epistemic care, convergence, and artifact handoff.
- Kept Sensemaking Protocol v0.1.0 unchanged.

## Sensemaking Skill v0.1.0 — 2026-08-22

- Added a standalone, repository-scoped agent skill implementing Protocol v0.1.0.
- Added a mandatory framing checkpoint for ambiguous decision scopes and objectives.
- Added proportional quick-check, full-case, and rigorous-case routing.
- Added self-contained protocol and case-template resources for isolated agents.
- Added five behavioral cases covering premature solution selection and over-processing.

## v0.1.0 — 2026-08-22

Status: frozen initial draft.

- Defined when the protocol should and should not be used.
- Established the Question → Objective → Reality → Unknowns → Possibilities → Evidence → Decision → Action loop.
- Distinguished diagnostic, decision, strategy, and prediction questions.
- Added explicit separation of observation, evidence, interpretation, and assumption.
- Added proportional rigor and stopping rules.
- Added a minimal, version-matched case template.
- Defined the first dogfooding experiment.

# Changelog

All notable changes to the Sensemaking Protocol are recorded here.

## Unreleased

- Added a Claude Code skill (`.claude/skills/sensemaking/`) that applies protocol v0.1.0, with bundled copies of the frozen artifacts and `scripts/check-skill-sync.sh` to detect drift. No protocol change.

## v0.1.0 — 2026-08-22

Status: frozen initial draft.

- Defined when the protocol should and should not be used.
- Established the Question → Objective → Reality → Unknowns → Possibilities → Evidence → Decision → Action loop.
- Distinguished diagnostic, decision, strategy, and prediction questions.
- Added explicit separation of observation, evidence, interpretation, and assumption.
- Added proportional rigor and stopping rules.
- Added a minimal, version-matched case template.
- Defined the first dogfooding experiment.
